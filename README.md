# Smart Symptom Triage System

Helping Nurses Send Patients to the Right Department, Fast.

Built by Francisca Kelechi 

## What it does
- Patient selects up to 5 symptoms
- Model predicts Recommended Department and Urgency Level
- Model: Random Forest Classifier
- Built for hospital triage support and education only. It does not replace a doctor.

## How to run locally
pip install -r requirements.txt
python app.py

## Tech
Python, Gradio, Pandas, Scikit-learn
